# LuzLink

Iluminación inteligente para tu hogar en Argentina.

## ¿Qué es LuzLink?

LuzLink es un proyecto innovador pensado para llevar la iluminación inteligente a los hogares argentinos. Nuestro objetivo es que puedas controlar las luces de tu casa desde cualquier lugar, usando solo tu celular o computadora. Ya no tendrás que preocuparte por dejar las luces encendidas: con LuzLink, podrás apagarlas o encenderlas de forma remota, programar horarios y crear escenas personalizadas para cada ambiente.

**¡No necesitás cambiar tus bombillas!** LuzLink se adapta a las lámparas y bombillas que ya tenés en tu casa.

## ¿Cómo funciona?

- **Parte digital:** Desde nuestra plataforma web, puedes acceder fácilmente a la opción de encender y apagar las luces de tu casa. También podrás programar horarios y automatizar acciones para ahorrar energía y mejorar la seguridad de tu hogar.
- **Parte física:** Instalamos en tu casa los componentes necesarios para que todo funcione de forma segura y sencilla. Podés seguir usando tus bombillas comunes, ya que el sistema se instala en las lámparas existentes.

## Beneficios

- **Ahorro energético:** Controla el consumo y evita gastos innecesarios.
- **Seguridad:** Simula presencia en tu hogar cuando estás fuera.
- **Comodidad:** Maneja todas las luces desde tu celular, sin importar dónde estés.
- **Personalización:** Crea escenas para cada momento del día.
- **Sin cambiar tus bombillas:** Usá tus lámparas y bombillas actuales.

## Preguntas frecuentes

**¿Tengo que comprar bombillas especiales?**  
No, podés seguir usando las bombillas comunes que ya tenés en tu casa. LuzLink se adapta a tus lámparas y focos actuales.

**¿Qué hago si se me quema el foco después de la instalación?**  
Solo tenés que reemplazarlo por otro foco nuevo, como lo harías normalmente. No es necesario llamarnos para cambiar una bombilla fundida.

**¿Se puede usar con bombillas LED?**  
Sí, LuzLink es compatible con bombillas LED, incandescentes y de bajo consumo. Te recomendamos usar LED para ahorrar energía y que duren más.

**¿Puedo controlar las luces desde mi celular?**  
¡Sí! Podés encender y apagar las luces desde tu celular, tablet o computadora, desde cualquier lugar donde tengas internet.

**¿Necesito internet en mi casa para que funcione?**  
Sí, el sistema necesita conexión a internet para que puedas controlarlo de forma remota. Sin embargo, podés usar las luces normalmente desde los interruptores de tu casa aunque no tengas internet.

**¿Qué pasa si se corta la luz?**  
Cuando vuelve la luz, el sistema se reinicia automáticamente y las luces quedan en el estado que tenían antes del corte.

**¿Es seguro instalar LuzLink?**  
Sí, la instalación la realizamos siguiendo todas las normas de seguridad eléctrica y el sistema está protegido contra cortocircuitos.

**¿Puedo programar horarios para que las luces se enciendan y apaguen solas?**  
¡Claro! Podés programar horarios para encender y apagar las luces, crear escenas y automatizar acciones según tus necesidades.

**¿Qué pasa si me mudo o quiero llevarme el sistema a otra casa?**  
Podés llevarte LuzLink a otra casa. Solo necesitás que un electricista desinstale y reinstale los módulos en la nueva vivienda.
